文字ならべ - 水族館シリーズ（PWA版）

このフォルダー内のファイルをすべて同じ構成のまま、HTTPS対応のWebサーバーに公開してください。
（ローカルでの動作確認は localhost でも可能です。）

1. Webサーバーで index.html を開きます。
2. 一度オンラインでページを読み込み、オフライン用ファイルの保存が完了するまで待ちます。
3. iPhone の Safari なら「共有」→「ホーム画面に追加」、Android の Chrome なら「アプリをインストール」などを選びます。
4. 2回目以降はオフラインでもゲームを遊べます。

注意: index.html をファイルとして直接開く (file://) だけでは PWA をインストールできません。
